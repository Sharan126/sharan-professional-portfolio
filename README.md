## 🚀 Running Locally

No complex build pipeline required. Everything runs natively using standard web standards:

1. In the project folder, start a local HTTP server:
   ```bash
   python -m http.server 8000
   ```
2. Open your browser to:
   ```
   http://localhost:8000
   ```
3. To test the résumé download, ensure `resume.pdf` remains in the root folder alongside `index.html`.

## 🌐 Deployment

### GitHub Pages (Recommended)
1. Push this repository to GitHub.
2. Go to **Settings** → **Pages**.
3. Under **Branch**, select `main` (or `master`) and folder `/ (root)`.
4. Click **Save**. Your site will be live at `https://<username>.github.io/<repo-name>/`.

### Vercel / Netlify
1. Connect your GitHub repository.
2. Keep the build command empty (static HTML).
3. Deploy directly.
